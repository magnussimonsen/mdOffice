% Difference from standard.tex: no author/date field, and no separate title
% page. \maketitle prints only the title (colored bar or plain bold) and
% body text begins directly below it on page 1 -- there is no \newpage.
%
% Because both branches below fully redefine \maketitle (rather than using
% titling's default \maketitle + \preauthor/\predate hooks), author/date are
% guaranteed never to appear, regardless of what's set in frontmatter: the
% custom \maketitle body here simply never reads \theauthor/\thedate. Trying
% to suppress them via `\author{}`/`\date{}` instead does NOT work reliably
% -- pandoc's own template assigns \author{$author$}/\date{$date$} AFTER
% header-includes are spliced in, so it overwrites any clearing done here.

% Pandoc's own template sets `\setcounter{secnumdepth}{-\maxdimen}` (no
% heading numbers at all) unless a document sets `numbersections: true`.
% Exam headings are numbered by default (see formats/pdf.py, which defines
% \forcenumbersections unless the frontmatter has an explicit
% `numbersections: false`), so restore article.cls's normal depth here --
% but only when that default wasn't opted out of.
\ifdefined\forcenumbersections
  \setcounter{secnumdepth}{3}
\fi

% mdOffice's exam-style documents conventionally start body content at `##`
% (pandoc's top-level `#`/\section is left unused; the document's own
% `title:` frontmatter serves that role instead). Left as-is, \subsection's
% default \thesubsection is "\thesection.\arabic{subsection}", which prints
% as "0.1", "0.2", ... since \section is never incremented. Numbering
% \subsection independently of the unused \section counter fixes that.
\renewcommand{\thesubsection}{\arabic{subsection}}
\renewcommand{\thesubsubsection}{\thesubsection.\arabic{subsubsection}}

\subsection{Use AI to generate template markdown and LaTeX
code}\label{use-ai-to-generate-template-markdown-and-latex-code}

Inline math looks like this: \(x^2 - 5x + 6 = 0\) has two real roots.
Solve it and plot it side by side, in the same PDF, with no separate
diagramming tool:

\begin{figure}[h]
\centering
\begin{minipage}[c]{0.42\textwidth}
\begin{align*}
x^2 - 5x + 6 &= 0 \\
x &= \frac{5 \pm \sqrt{(-5)^2 - 4\cdot 1\cdot 6}}{2\cdot 1} \\
x &= 2 \quad \text{or} \quad x = 3
\end{align*}
\end{minipage}
\hfill
\begin{minipage}[c]{0.5\textwidth}
\centering
\begin{tikzpicture}
\begin{axis}[axis lines=middle, xlabel={$x$}, ylabel={$y$}, xmin=-1, xmax=6,
  ymin=-3, ymax=8, width=6cm, height=6cm, domain=-0.5:5.5, samples=100]
\addplot[thick, blue] {x^2 - 5*x + 6};
\addplot[only marks, mark=*, red] coordinates {(2,0) (3,0)};
\end{axis}
\end{tikzpicture}
\end{minipage}
\caption{Solving $x^2 - 5x + 6 = 0$ and its graph, side by side}
\end{figure}
