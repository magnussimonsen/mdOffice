# AI instructions — math documents

## Math formatting

- Use the LaTeX `align` environment for all multi-line calculations.
- Use `$$` for standalone single-line equations and `$...$` for inline math.

## Language and level

- Write for high school students. Keep explanations clear and step-by-step.
- Avoid advanced notation or terminology not covered in a standard high school curriculum.
- Briefly name the method or rule being applied before using it (e.g. "Using integration by parts:" or "Applying the quadratic formula:").

## Solutions to word problems

Every solution to a word problem must end with a clearly formatted answer sentence, for example:

**Answer:** The number of apples is 4.

The answer sentence should restate what was asked, use correct units, and be written in plain language.
