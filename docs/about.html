About mdOffice

Why this project exists, and who it's for.

mdOffice is an open-source tool for writing in plain Markdown and LaTeX, and generating PDF, DOCX, ODT, PPTX, EPUB, or Beamer output automatically. It's for developers, teachers, and anyone else who'd rather write in plain text than fight a word processor's menus to get a document looking right.

I'm Magnus Simonsen, a high school STEM teacher, and I built mdOffice because making exams, handouts, and other work related documents in a word processor kept getting in the way of actually writing them. I also wanted a workflow that let me use VS Code as my editor, so I could take advantage of its customization options and its AI integration (in GDPR-compliant workspaces only).

In mdOffice, a handout and its solutions live in a single file. Custom macros mark which blocks are solution-only, so the user can toggle switches between the student handout and the answer key, without maintaining two documents that can drift out of sync.

mdOffice is in continuous development, and new features or fixes are added often.

If you find mdOffice useful, a ⭐ on the GitHub repo costs nothing and helps others find it. If you'd like to support the project directly, see the Support me link in the top bar.

Special thanks to the maintainers of Pandoc, the document converter mdOffice is built on, and to the creators of the two VS Code extensions that tie it all together: Run on Save and Highlight. Please give them all a ⭐ on GitHub.
