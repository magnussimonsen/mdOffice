The menu-free and AI-friendly Office suite in VS Code

mdOffice is an open-source tool for writing in plain Markdown and LaTeX, and generating PDF, DOCX, ODT, PPTX, EPUB, or Beamer presentations automatically. It's for developers, teachers, and anyone else who'd rather write in plain text than fight a WYSIWYG word processor to get a document looking right.

Why mdOffice?

Traditional word processors can be awkward for technical writing and mathematical notation. Pure LaTeX can also become verbose. Markdown with small LaTeX and pgfplots blocks is easier to read and edit. Markdown, LaTeX, and pgfplots are also preferred formats for AI assistants.

  • Write in Markdown (with LaTeX and pgfplots blocks) and auto-build on save directly in VS Code.
  • Export to PDF, DOCX, ODT, PPTX, Beamer, or EPUB.
  • Select output formats at the top of each file; each format is saved in its own output folder.
  • Use built-in document styles or create reusable custom LaTeX themes.
  • Open-source (MIT), built with Python, Pandoc, LaTeX, Lua, and VS Code extensions, and fully customizable with your own macros and keybindings.

One YAML block per document

A frontmatter block at the top of the file controls the document: doc-style: exam picks the theme, titlebg colors the title block, show-solution / show-blankbox toggle whether answers appear, and ai-instructions adds guidance for AI assistants editing the document.

The frontmatter is split into two parts: standard Pandoc keys, which control the document title, author, and date, and mdOffice's own keys, which control the theme, logo, and other document-specific settings.

One markdown file, three handout document types

Two frontmatter flags, show-solution and show-blankbox, control which parts of a quiz or exam show up in the generated PDF. The same markdown file produces a question sheet, an answer key, or a worksheet with room to write, depending on how they're set:

show-solution: false
show-blankbox: false

With both flags set to false, the PDF shows only the questions.

Set show-solution: true and the same file renders each task's worked solution in a labeled box right below the question, ready to hand out as an answer key.

Set show-blankbox: true instead, and each task gets a blank, bordered box for students to write their own solution in, turning the same handout into a worksheet.

As shown in the code screenshot, blank boxes are added with the Lua macro :::blankbox (Number of blank lines) :::, or, equivalently, with the attribute syntax ::: {.blankbox lines=10} :::. If no number of lines is given, mdOffice defaults to 5 blank lines (the default can be changed in _core/scripts/filters/solution_filter.lua). Solution blocks are added the same way, with the Lua macro :::solution (The solution goes here) :::.

One file defines the slide theme

Custom LaTeX themes control logo placement, colors, and title layout in one file. The built-in fancybeamer theme gives every slide a full-width colored header bar that you switch per slide with a macro like \blueheader, \cyanheader, \greenheader or \grayheader, plus matching theorem boxes (bluebox, cyanbox, …), focus boxes (bluefocus, greenfocus, …), and warning/info callouts for flagging what's in or out of the syllabus.

That slide is plain Markdown: a \blueheader macro sets the title bar color, a .columns fenced div lays out the two-column grid, and bluebox* / bluebox / bluefocus environments render the boxes. No LaTeX beyond the theme file itself is needed.

In VS Code, mdOffice also highlights these environment blocks directly in the Markdown source: bluefocus, redfocus, greenfocus, cyanfocus, and grayfocus, plus matching theorem boxes such as bluebox/bluebox* (and the red, green, cyan, and gray variants). The same color system used by the slide theme is mirrored in the editor, so headers, box frames, and focus sections are easy to scan while writing.

AI instructions live in mdoffice.ai-instructions

Note to all users: make sure any AI assistant you connect stays compliant with GDPR (or your institution's data-protection rules) before pointing it at your workspace.

Add a mdoffice.ai-instructions key to the frontmatter to give AI assistants a set of instructions to follow when editing the document. The instructions are passed to the AI model along with the document content, so its edits stay consistent with your preferences.

Point it at reusable rule files instead of inlining instructions per document. mdOffice compiles them into a CLAUDE.md next to the file, which Claude Code, Cursor, or any other assistant picks up automatically.

---
mdoffice:
  ai-instructions:
    - "../ai-instructions/math.md"
    - "../ai-instructions/text.md"
---

LaTeX plots with pgfplots

Plot functions directly in LaTeX (pgfplots) inside the Markdown. The plot and the surrounding math are compiled together by xelatex into one vector figure, with no separate plotting tool or screenshot involved.

LaTeX diagrams with TikZ

Draw flowcharts directly in LaTeX (TikZ) inside the Markdown. Pandoc passes the TikZ code straight to xelatex, which renders it as a vector diagram in the PDF.

mdoffice.py validate flags unknown frontmatter keys, like haeder instead of header, before a mistake silently disappears into an unstyled document.
