Getting Started on Windows, macOS and Linux

Recommended: run one install script. Done in a minute.

  1. Run the install script (recommended)

    This sets up .venv, installs Python requirements, writes .vscode/settings.json, and checks Pandoc/LaTeX.

    Windows (CMD or PowerShell) 
    _core\scripts\setup\install_windows.bat
    Linux / macOS (bash) 
    bash _core/scripts/setup/install_linux.sh

    Both scripts also verify required LaTeX packages from _core/scripts/setup/latex-required-packages.txt.

  2. Manual fallback (if you prefer)

    Only use this if you don't want the script above.

    Windows 
    winget install --id JohnMacFarlane.Pandoc

    Then install MiKTeX for xelatex.

    Linux 
    sudo apt install pandoc texlive-xetex texlive-latex-extra texlive-fonts-extra
    macOS 
    brew install pandoc

    Then install MacTeX for xelatex.

    Verify both are on PATH:

    pandoc --version
xelatex --version
    Windows 
    python --version
py -3.14 --version
    Linux / macOS 
    python3 --version
python3.14 --version

  3. Save a Markdown file and watch it build

    Open one of the ready-to-use files in _core/examples/, or start your own with mdoffice.make-pdf: true in the frontmatter. Saving the file runs the build automatically and drops the output next to it.

Full reference: the README covers every frontmatter key, custom LaTeX themes, and troubleshooting for each step above.
